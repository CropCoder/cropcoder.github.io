## Project Overview

Personal academic portfolio site for Jiwen Zhao — a bioinformatics and crop disease resistance researcher. Hosted on GitHub Pages at `cropcoder.github.io`. Static HTML/CSS/JS site with blog articles in English.

## Architecture

```
├── index.html                      # English resume homepage (single-page sections + hero)
├── 404.html                        # Branded 404 page (standalone, inline styles)
├── robots.txt / sitemap.xml        # Search engine crawl + index
├── blog/
│   ├── index.html                  # Blog listing page (all posts)
│   ├── gwas-analysis.html          # Blog: GWAS analysis tutorial
│   ├── rice-disease-resistance.html # Blog: Rice disease resistance review
│   ├── pangenome-research.html     # Blog: Pan-genome research notes
│   └── hpc-gpu-genomics.html       # Blog: HPC/GPU for genomics
├── newpaper/
│   ├── index.html                  # Daily literature briefing archive index (zh-CN, client-side search)
│   └── 2026-MM-DD-日报.html        # Self-contained daily briefing issues (12 direction tags)
├── assets/
│   ├── css/resume.css              # Single stylesheet (~1450 lines)
│   └── js/resume.js                # Nav toggle + scroll-spy active link + [data-year] auto year
├── images/                         # Favicons, profile photo, publication figures, og-image.jpg
├── pdf/                            # Publication PDFs (linked from homepage)
├── .github/FUNDING.yml
├── .nojekyll                       # Disables Jekyll processing for GitHub Pages
└── .gitignore
```

### Key design decisions

- **No build step.** Pure HTML + CSS + JS — `index.html` is the English resume homepage. All resume/blog pages include the same `resume.css` and `resume.js`.
- **Named you must know:** CSS uses BEM-like naming (`site-header`, `hero-copy`, `edu-card`, `life-card`). JS uses data attributes (`[data-nav]`, `[data-header]`) for hooking elements.
- **Blog pages** share the same header/nav structure as the resume pages; nav links point to homepage anchors (`../index.html#research`) or sibling blog pages.
- **Active nav link** is driven by a scroll-spy in `resume.js`; blog pages set `.is-active` statically in HTML.
- **Responsive layout** in CSS uses `@media (max-width: 720px)` breakpoint.
- **No dependencies.** No frameworks, no package manager, no bundler.

## Adding a new blog post

1. Create `blog/<slug>.html` starting from an existing blog page as template.
2. Copy the `<header>` block (with shared nav) and the `<script>` tag.
3. Add an entry in `index.html` under `#resources` — a card linking to `blog/<slug>.html`.
4. Add an entry in the `blog/` page nav if relevant.

## Adding a new daily briefing issue

1. Drop `newpaper/2026-MM-DD-日报.html` in place (generated by `fetch_daily.py`, outside this repo).
2. Prepend an entry to the `ISSUES` array in `newpaper/index.html`.
3. Add the URL to `sitemap.xml` with the issue date as `lastmod`.
4. Each issue's TOC must only reference `<section id>` values that actually exist in that page — the TOC is per-issue because sections vary by which of the 12 directions have papers that day.

## SEO conventions

- Every page carries `canonical`, `robots`, `keywords` (include name variants: 赵记稳 / Jiwen Zhao / zhao jiwen / zhaojiwen / CropCoder), and OpenGraph/Twitter meta.
- `index.html` has JSON-LD `Person`; blog pages and daily issues have JSON-LD `Article`; `newpaper/index.html` has JSON-LD `Blog`.
- Footer copyright uses `<span data-year>` — `resume.js` fills in the current year; don't hard-code years.
- After structural changes, regenerate `sitemap.xml` (50 URLs as of 2026-11, daily issues use their publish date as `lastmod`).
- IndexNow: the key file `40b17750855086a4e63b2d7f7b457f5d.txt` at the site root verifies ownership; after publishing updates, POST the changed URLs to `https://api.indexnow.org/indexnow` with body `{"host": "cropcoder.github.io", "key": "40b17750855086a4e63b2d7f7b457f5d", "keyLocation": "https://cropcoder.github.io/40b17750855086a4e63b2d7f7b457f5d.txt", "urlList": [...]}` — this pings Bing/Yandex/Naver/Seznam at once.
